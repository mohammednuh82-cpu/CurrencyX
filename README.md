# CurrencyX

CurrencyX is a simple currency converter web application built using HTML, CSS and JavaScript.

## Features

- Convert between different currencies
- Simple and clean interface
- Responsive design
- JavaScript-based currency conversion
- Easy to use

## Technologies Used

- HTML
- CSS
- JavaScript
